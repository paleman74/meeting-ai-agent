# Meeting AI Agent

A privacy-first AI assistant that can listen to meetings, extract decisions, identify action items, and generate summaries.

## Vision

Create a local AI agent capable of:

- Capturing meeting audio
- Capturing microphone audio
- Transcribing conversations
- Identifying speakers
- Extracting decisions and action items
- Generating meeting summaries
- Preserving user privacy by running locally

## Architecture Roadmap

### Phase 1
Audio capture validation

### Phase 2
Speech-to-text using Whisper

### Phase 3
Speaker identification (diarization)

### Phase 4
Meeting memory and context management

### Phase 5
Local LLM summarization

### Phase 6
Real-time meeting intelligence
